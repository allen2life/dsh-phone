# 小手机 · dsh-phone

DSH 右下角的一部小手机：点圆按钮弹出来，桌面上排着应用图标，点图标在屏幕里打开。

应用是 `.dshapp` 压缩包，在手机里导入，**随装随用，不用刷新页面、不用重启 DSH**。

手机壳是插件，应用不是。这条分开，后面所有设计都跟着它走。

---

## 装

从 GitHub：

```sh
dsh plugin add github:<你的用户名>/dsh-phone
```

从本地目录（开发时用）：

```sh
dsh plugin add <这个目录的绝对路径>
```

装完右下角应该立刻出现圆按钮，不用做别的。改完代码要重启 DSH，或者把插件关一次再打开。

---

## 用

| 想干什么 | 怎么做 |
|---|---|
| 打开手机 | 点右下角那个圆按钮 |
| 收起手机 | 点手机顶栏最右边的叉 |
| 装一个应用 | 点顶栏的 **＋** 选一个 `.dshapp`；或者直接把文件拖到手机上 |
| 打开应用 | 点图标 |
| 回到桌面 | 点应用顶栏左上角的返回 |
| 卸载应用 | 长按图标（约半秒），或者右键 |

装完立刻能用，桌面上马上多一个图标。

**空桌面不是一片空白**，会告诉你怎么装。

## 写一个自己的应用

应用是一个普通 zip，把后缀改成 `.dshapp`，里面三样东西：

```
我的应用.dshapp
├── manifest.json    必须有
├── main.js          必须有，入口
└── icon.svg         必须有（svg / png / jpg / webp 都行）
```

`main.js` 交出一个挂载函数，必须返回一个卸载函数：

```js
module.exports = function mount(ctx) {
  const title = document.createElement('div');
  title.textContent = '你好';
  ctx.root.appendChild(title);

  return function unmount() {
    // 停定时器、停音频、清 DOM
  };
};
```

手机交给应用的东西、清单字段、错误行为，全在 **[docs/app-contract.md](docs/app-contract.md)**。

想照着抄，看 `apps-src/note-book/`——一个 5KB 的便签本，把存储和语言都走了一遍。

打包：

```sh
node dev/pack-app.mjs note-book     # → dist/note-book.dshapp
```

## 数据在哪

都在 DSH 主目录下（不是插件代码目录），所以换插件版本、重装插件，装过的应用都还在。

| 东西 | 位置 |
|---|---|
| 装的应用 | `<DSH 主目录>/dsh-phone/apps/<应用id>/` |
| 应用的私有设置 | `<DSH 主目录>/dsh-phone/apps/<应用id>.json` |
| 手机自己的设置 | `<DSH 主目录>/dsh-phone/phone.json` |

`DSH 主目录` 默认是 `~/.dsh`。

## 尺寸和位置（硬要求，不打算改）

| 部位 | 尺寸 |
|---|---|
| 圆按钮 | 40 × 40 |
| 整机外框 | 280 × 420，圆角 20 |
| 内屏（应用能画的地方） | **264 × 340** |
| 顶栏 | 高 30 |

内屏 264 × 340 是钉死的：应用按这个尺寸画，改了就会挤。

位置：右边贴着对话内容区那条走廊，底边离输入框下边缘固定距离（输入框长高长矮都不动）。右侧栏宽过 420 像素把走廊占掉时，整个手机淡出。

## 限制，以及我知道但没解决的

**没有安全沙箱。** 应用代码和手机跑在同一个页面里，没有 iframe、没有 Worker。清单里的权限只能挡住"不知道自己该要什么"的应用，挡不住故意写坏的应用。**只装你信任的应用。**

具体说，一个装进来的应用实际上能做到这些（我们拦不住）：

- 直接调手机自己的接口，装别的应用、卸别的应用、读别的应用的设置
- 直接访问同一个站点上的任何地址
- 碰手机的界面结构

这条不是疏忽，是设计取舍：做真沙箱要么上 iframe（那 `ctx.root` 这块容器就没法给了），要么每个应用单独起进程。本轮都不做。

**其他限制：**

- 一次只能开一个应用。放歌的那个是例外。
- 应用不能自己带 React，只能用手机给的那一份。
- 只能从本地文件导入，没有应用商店。
- 应用不能上网。要数据就找它自己的后端，由宿主半去取。

## 怎么跑测试

```sh
node dev/run-all.mjs
```

四份：宿主半的解压与装卸、宿主 HTTP 接口、界面半的注册与结构、端到端（真装包、真跑应用、真存盘）。

单独跑：

```sh
node dev/host-test.mjs
node dev/host-http-test.mjs
node dev/client-smoke.mjs
node dev/e2e-test.mjs
```

测试用临时目录当 DSH 主目录，不碰你真实的 `~/.dsh`。

## 代码结构

| 文件 | 干什么 |
|---|---|
| `index.js` | 宿主半入口：开 `/dsh-phone/api`，按 `{ method, params }` 分派 |
| `lib/zip.js` | 自己写的 zip 读取器（只用 Node 自带 zlib），含路径穿越检查 |
| `lib/apps.js` | 清单校验、装/卸、私有存储、应用登记表 |
| `lib/forward.js` | 替应用转后端请求，权限判断在这里 |
| `client.js` | 网页半：圆按钮、桌面、应用窗口、导入、动效、位置计算 |

落盘的活全在宿主半，界面半一次都不碰文件系统。
